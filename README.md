# Duolingo Trips (concept prototype)

An etiquette-first trip-prep concept for Japan and Korea, built by SVR Consulting for the think-cell Global Case Competition 2026.
Illustrative only. Not an official Duolingo product.

Live app: https://sebastianlew06.github.io/duolingo-trips/

- `index.html`: the app
- `manifest.webmanifest` and `icons/`: lets phones install it with "Add to Home Screen"
- `sw.js`: keeps it working offline after the first visit. Change `VERSION` whenever `index.html` changes.
